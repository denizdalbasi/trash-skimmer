This file contains a draft idea of how the folder management can look for the hardware.


STM32 Main Firmware
 - Contains all the main functionalities, physical features, etc.

STM32_Skimmer_Firmware/
├── Core/
│   ├── Inc/
│   │   ├── main.h                 # Pin definitions, HAL includes, clock setups
│   │   ├── config.h               # Global calibration constants (PID gains, thresholds)
│   │   │
│   │   │   /* --- Hardware Drivers --- */
│   │   ├── motors.h               # Motor/ESC control definitions (PWM 1000-2000us)
│   │   ├── imu.h                  # MPU-6050 / GY-87 / Compass I2C driver
│   │   ├── gps.h                  # NEO-6M NMEA sentence parser
│   │   ├── sonar.h                # JSN-SR04T non-blocking ultrasonic driver
│   │   │
│   │   │   /* --- Logic & Processing --- */
│   │   ├── pid.h                  # Heading-hold PID steering math
│   │   ├── navigation.h           # Waypoint math (Haversine distance & bearing)
│   │   ├── vision_link.h          # UART packet parser for Pi Zero data
│   │   └── state_machine.h        # System operational states & transitions
│   │
│   └── Src/
│       ├── main.c                 # System init, hardware timers, non-blocking scheduler
│       ├── config.c               # Default configurations
│       │
│       │   /* --- Hardware Drivers --- */
│       ├── motors.c               # ESC arming sequence & PWM generation
│       ├── imu.c                  # I2C reads, hard-iron offsets, gyro rate extraction
│       ├── gps.c                  # Circular DMA UART buffer & latitude/longitude extraction
│       ├── sonar.c                # Non-blocking trigger and echo pulse measurement
│       │
│       │   /* --- Logic & Processing --- */
│       ├── pid.c                  # Calculates differential steering offset (u = Kp*e + Kd*de)
│       ├── navigation.c           # Calculates target heading to base dock
│       ├── vision_link.c          # Decodes Pi Zero serial messages (e.g., target offset Δx)
│       └── state_machine.c        # State switches (IDLE -> SKIMMING -> AVOID -> RTB)
│
└── Drivers/                       # STM32 HAL libraries (generated by CubeMX)

Raspberry Pi Trash Detection
 - Communicates with STM32 through UART at 115200 baud frequency

~/skimmer_vision/
├── config.py             # Resolution, camera IP address, baud rate, debug flags
├── video_stream.py       # Threaded RTSP/MJPEG reader (pulls from ESP32-CAM)
├── detector.py           # Runs OpenCV color masking, ArUco detection, or TFLite
├── stm32_comm.py         # Formats and sends UART packets over /dev/ttyAMA0
└── main_vision.py        # Main execution loop

ESP32 Camera Stream
 - Communicates with Raspberry Pi through Wi-Fi

ESP32_Camera_Streamer/
├── CameraPins.h          # Hardware pin definitions for the OV2640 sensor
└── ESP32_Camera_Streamer.ino  # Boots Wi-Fi Access Point & serves MJPEG stream
